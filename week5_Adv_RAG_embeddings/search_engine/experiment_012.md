# Experiment 012

## Title
Keyword Search vs Semantic Search

## Objective
Compare exact word matching with meaning-based retrieval.

## Test Query
database connect problem

## Observations
- Keyword search only matched exact words.
- Semantic search found related concepts.
- Synonym expansion improved retrieval quality.

## Key Learning
Modern RAG systems use embeddings because they capture semantic similarity rather than relying only on exact keyword overlap.

## Conclusion
Semantic search retrieves more relevant documents when users phrase questions differently from the stored knowledge base.
