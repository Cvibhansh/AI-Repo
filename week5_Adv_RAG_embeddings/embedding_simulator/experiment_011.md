# Experiment 011

## Title
Understanding Embeddings

## Objective
Learn how AI represents the meaning of text using numerical vectors.

## Mini Project
Built a simple similarity search engine using Python.

## Observations
- Keyword overlap can approximate similarity.
- AI embeddings go beyond exact word matching.
- Similar concepts can be mathematically close.

## Questions
- Why are vectors useful?
- How do embeddings improve RAG?
- What are the limitations of keyword search?

## Conclusion
Embeddings allow AI systems to compare the meaning of text rather than relying only on exact keywords.
