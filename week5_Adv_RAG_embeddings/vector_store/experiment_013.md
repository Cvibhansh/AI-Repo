# Experiment 013

## Title
Building a Simple Vector Store

## Objective
Understand how AI systems store and retrieve document embeddings.

## Components
- Fake document embeddings
- Vector store
- Distance calculation
- Similarity search
- Local RAG pipeline

## Observations
- Documents can be represented as vectors.
- Smaller vector distance means greater similarity.
- Retrieving context before calling the LLM improves answer quality.

## Conclusion
A vector store acts as a searchable memory for AI systems and is a core building block of RAG.
